

📝 Конспект: Развертывание базового стенда (Модуль 0)





Окружение (Хост)



• ОС: Windows 10/11 x64

• Среда виртуализации: Oracle VirtualBox 7.x

• Гостевая ОС (Linux): Ubuntu Server 24.04 LTS (без GUI)



Параметры виртуальной машины (node-1)



• CPU: 1 vCPU

• RAM: 2048 MB (2 ГБ)

• Диск: 25 GB (динамический vdi)

• Сеть: NAT (базовый режим VirtualBox для доступа виртуалки в интернет)



Ключевые шаги при установке (Runbook)



1\. Отключение автоматизации: При создании машины в VirtualBox была снята галочка Proceed with Unattended Installation. Это позволило запустить интерактивный ручной установщик СУБД/ОС.

2\. Разметка диска: На этапе Storage configuration выбрана автоматическая разметка всего диска с использованием LVM (Logical Volume Manager). Действие подтверждено через Continue.

3\. Учетная запись: Создан системный пользователь (записать свой логин), задано имя сервера node-1.

4\. Служба удаленного доступа (Критично): На этапе SSH Setup с помощью клавиши Пробел была активирована опция Install OpenSSH server. Это позволит в дальнейшем управлять сервером из Windows-терминала по порту 22, не используя медленный интерфейс VirtualBox.

5\. Завершение: После этапа Installing kernel выполнена перезагрузка через Reboot Now и извлечен виртуальный ISO-диск.
